# 浏览器本地小模型

使用开放基础模型 Qwen3-0.6B 的 MLC 4-bit 量化版本。模型由 Qwen 团队训练，MLC 提供转换版本；本项目自行集成、部署浏览器推理组件，并未声称自行预训练或微调模型。推理通过 WebLLM 0.2.86 在用户设备 WebGPU 上完成，无 API key，无云端推理调用。

只有用户点击加载后才下载模型。检索、筛选与基础建议不要求模型运行。首次加载从部署站点下载公开权重（若配置为上游地址则连接 Hugging Face）；托管服务可能看到常规下载请求元数据，问题内容由本地 Worker 处理。浏览器可能缓存权重，缓存可能被清理；卸载释放运行资源，不承诺删除浏览器缓存。

模型仓库为 https://huggingface.co/mlc-ai/Qwen3-0.6B-q4f16_1-MLC ，固定 revision `8c14ce481d4c692769976ad52afea453a102df19`。通过仓库文件树及 ndarray-cache.json 核实：权重分片 335,372,288 bytes，仓库文件总计 351,517,143 bytes（约 352 MB，低于 1 GB；实际下载受缓存、运行时文件影响）。元数据在开发网络通过 hf-mirror.com 镜像获取。权重可由 `scripts/vendor-model.py --weights` 下载至 `.cache/model`，官方源限时尝试后采用公共镜像，文件须校验固定 revision 的 SHA256。发布时将权重放在站点 `models/qwen3/resolve/main/`，由 GitHub Pages 同源提供；源代码仓库不保存大权重。基础模型与运行时均为 Apache-2.0，许可证随站点保存。

运行时 JS 从官方 npm `@mlc-ai/web-llm@0.2.86` 获取，并核对 npm sha512 integrity。WASM 为官方 binary-mlc-llm-libs 中 Qwen3-0.6B-q4f16_1_cs1k-webgpu.wasm，按 Git blob `2074819d0f0d77654d4fe9b3ce7f2aa29212c04b` 验证并随站点托管。`scripts/vendor-model.py` 可复现下载并验证运行时及 WASM，不下载权重。模型地址集中配置于 `web/model-config.json`，Worker 仅接受同源模型目录或官方 HTTPS 模型源和同源 WASM。

建议使用支持 WebGPU 的桌面浏览器与充足内存。官方运行配置估计显存需求约 1.4 GB，context window 为 4096 tokens。可用性检查只证明 WebGPU adapter 存在，不保证设备能够加载模型。网络、显存、浏览器限制均可能导致加载失败。无 WebGPU 时使用页面原有检索结果；失败时显示中文错误并允许重试。加载限时 15 分钟，生成限时 3 分钟，停止会直接结束 Worker 并释放模型，继续使用需要重新加载。

首版采用证据筛选式回答。模型在JSON Schema约束下选择资料片段编号，最多256 tokens；程序再次验证编号合法性，只展示相应的原文摘录，不展示生成的自由事实。失败时回退到原始检索结果。模型仍可能选错或遗漏片段，因此不能视为就业保证、官方预测或职业建议的最终结论。较长片段以完整句界截取并标省略号。

已下载固定 revision 的全部 18 个仓库文件，总计 351,517,143 bytes；已核对全部文件大小及 LFS 文件上游 SHA256，并保存每个文件 SHA256 于 web/model-manifest.json。验证还包括配置和 WASM 工件完整性、无 WebGPU 环境回退、客户端流式消息、忙状态与取消行为；默认测试不下载权重。真实浏览器全模型下载、加载及生成是否完成，应以项目实际验收记录为准，单元测试不构成真实模型推理验证。
