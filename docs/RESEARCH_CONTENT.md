# 专业研究、行业研究与毕业去向证据

核验日期：2026-10-16。`content/research.json` 是编辑研究；`content/graduate-outcomes.json` 是带来源、统计期和分母的资料层。两者不能混作实时招聘或个人结果预测。

## 专业与行业研究契约

`research.json` 顶层包含 `updatedAt`、`kind: "editorial_research"`、`methodology`、`majors` 和 `industries`。最终专业、行业 ID 必须与 `catalog.json` 完全对应。

每个专业包含：

- `summary`：分支之间的实际差异与共同问题。
- `foundations`：3–5项具体课程或能力。
- `routes`：至少3个方向；每个方向包含 `title`、有效的 `roleIds`、`entry`、`progression`、`proof`、`tradeoff`。
- `degreeDecisions`：2–3项教育、深造或资格判断；`transferable` 和 `pitfalls` 各2项。
- `sources`：官方来源的 `title`、`url` 与 `scope`。来源可覆盖宽学科组，不把官方统计包装成对全部编辑建议的逐条证明。

三至五年是能力积累的讨论范围，不是晋升时间表。验证项目使用公开、合成或教学材料；临床、化学、设备、养殖等项目不会要求读者在无授权环境开展危险或受监管活动。跨专业路线写出需要补的课程和实践，不按人格标签、性别或其他身份给人分配职业。

每个行业包含 `profitPool`、3项 `companyChecks`、3项 `leadingSignals` 和2项 `weakSignals`。这些是用于查看财报、合同、经营记录或面试信息的编辑问题，不是已确认的某家公司经营事实。领先信号仅为可能提前暴露需求或交付变化的观察项，不能机械解释为价格或就业预测。公共服务采用资金与服务效果框架，不强行套用商业利润。

## 毕业去向数据契约

顶层为 `reviewedAt`、`methodology`、`groups`、`reports`。截至本次提取：67个统计组、400行数值、40个来源条目。

`groups` 的公共字段为 `id`、`title`、`region`、`majorIds`、`period`、`metric`、`dataKind`、`source`、`population`、`rows` 和 `limitations`。`rows` 保留 `occupation`、百分比单位的 `share`、`soc`；未从原表核验SOC时为 `null`，不能根据相近名称自动填入。

**界面和模型必须先读取 `metric` 与 `dataKind`。** 为兼容行结构，`occupation` 在非职业分布表中承载“指标行名称”，不能单凭这个键推断该行是职业。特别是中国组的“已落实毕业去向”不能生成岗位推荐，也不能接到工资、增长或招聘空缺指标。

### 美国：37组、370个职业比例

来源是已逐页浏览核对的 [BLS Field of Degree 官方索引](https://www.bls.gov/ooh/field-of-degree/home.htm) 中全部37页。每页提取 Table 2 的前十职业与第一项比例，并提取 Table 1 的就业人数、研究生或专业学位比例、处于通常至少要求学士学位的职业中的比例。未将工资或2024–34预测增长列混入历史职业分布。

- `dataKind` 为 `occupation_distribution`；本批实际统计期均为 **2023**，不是2026。
- 分母是相关学科组的在职学位持有者，包含后来取得更高学位的人，不是应届毕业生；本表不估计失业率或第一份工作分布。
- `degreeStats.advancedDegreeShare` 的分母是本学科组在职学位持有者。`bachelorsRequiredOccupationShare` 是职业通常教育要求分类，不是专业对口率。
- `source.publishedAt` 为 `null`：页面仅明示修改日期，本批将其保存为 `modifiedAt`，不擅自改称首次发布日期。
- 同一 `groupId` 可以关联多个 `majorIds`；工程大类、商科大类等数字不能分拆成中国细分专业的独立结果。
- 无足够直接学位对应关系的已收录组保留空 `majorIds`。没有硬把美国本科学科组套到临床与口腔医学专业学位或职业技能培训；当前US映射42个专业族。
- 前十项不覆盖全部职业；原表比例已四舍五入，不能要求合计为100，也不能将剩余项自动归为失业。

例如 [计算机与信息技术表](https://www.bls.gov/ooh/field-of-degree/computer-and-information/computer-and-information-technology-field-of-degree.htm) 中，软件开发人员占该学科组在职学位持有者的24%；这不是计算机应届生获得开发岗位的概率。所有学科组都有独立原表URL，数值没有用相邻学科填补。

### 中国：单校30个本科专业、30个去向状态比例

来源为 [上海商学院2025届毕业生就业质量年度报告](https://xxgk.sbs.edu.cn/xxgklm/xsswgl/bysjyzlndbg/8548fecb7c45406caf712f4d91ac73b4.htm) 表1-2，官方发布日2026-03-23，统计截至2025-08-28。提取30个本科专业、合计1941名本科毕业生的专业人数和初次毕业去向落实率，关联14个专业族。

- `dataKind` 为 `destination_status`；`metric` 明示“初次毕业去向落实率（含升学等）”。每个组只有一条原报告提供的落实比例。
- `sampleSize` 为该校该专业毕业人数。各专业各有组ID，不把不同专业或中外合作项目合并为一个比例。
- 原报告的该表没有给出各专业职业分布，故未推算各职业、雇主或收入；未据百分比逆推未公布人数。
- 单校、单届、较小专业样本，不代表全国或城市同专业就业。100%落实也不等于100%劳动就业、专业对口或稳定工作。

另核验了 [华北水利水电大学2025届报告发布页](https://www2.ncwu.edu.cn/xxgk/info/1048/2904.htm) 与 [上海政法学院2024届报告发布页](https://xxgk.shupl.edu.cn/2025/0217/c4059a137231/page.htm)。前者附件要求验证码，后者本轮未取得可核对的完整统计正文；二者只进入 `reports` 发现目录，不进入 `groups` 数值分析。`coverage` 明示边界，未用搜索摘要填比例，也未宣称这些是全国最新报告。

## 验证与维护

运行 `python3 -m unittest discover -s tests -p 'test_research.py' -v`。测试包括全部目录覆盖、ID与岗位引用、同专业路线和项目差异、全局去重、受监管跨专业边界、行业经营问题与反证、统计分母语义、跨期误标、CN/US数据类型分离、单校样本合计和多份官方原表数值锚点。

测试不能证明每条编辑判断在所有机构成立，也不代替当前资格规则核验。刷新数值时应一起复核原表、统计期、分母、教育口径与测试锚点；不能只替换页面日期。新报告只有在正文可读且分母明确时才进入数值组。资格、工作身份、雇主职位和经营状态的实时查询属于其他资料层。

目录中需持续注意的关联：航空航天专业原关联 `pilot` 不表示工程学位自动通往飞行员；动物与水产原来只有 `vet`，研究内容用相邻农业、食品与研究岗位说明额外训练；医学技术、心理和体育等专业不能通过相近岗位名推断共享执业权限。本次未修改目录本身。

## 发布时的合并与职业关联

`pipeline.build` 合并上述基础层与 `graduate-supplement.json` 中的华中科技大学、西安电子科技大学样本。当前公开产物为70组、415条比例记录、42条来源记录，其中40份统计页面/报告已取结构化数值，另2份只有发布页。中国33组45条，美国37组370条。所有本科、硕士、职业与行业分母保留独立，不求混合就业率。

美国原表的118个唯一英文职业名均与BLS详细职业行唯一完全匹配，构建时为370条记录附上SOC、匹配方法和来源，同时保留原英文和中文译名。名称相似但不完全相同、同名不唯一或Summary行均不连接。该步骤仅用于从岗位查看相关学科样本，不加入推荐指数。

## 大陆优先补充后的覆盖

最新合并为133组、592指标格，其中587个数值、5个未报告值。中国大陆96组、217个数值，来自5份已提取官方高校文档，关联31/44目录类别；不是31类全国代表样本。美国保留370条历史职业分布作为补充。完整报告目录44条，42条来源已有结构化数字，2条仅核验发布页。新增6条同一银行集团官方条件只用于具名历史岗位核对，不能估计录用难度。
