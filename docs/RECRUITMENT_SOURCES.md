## 正文如何核验

普通静态读取建行公告页只返回 {{detail.annoContent}} 模板。实际从该站 /cn/job/v3/js/announcement.js 与 /cn/job/v3/js/job_public.js 确认公开查询操作 TXCODE=NHR106，再以匿名会话、公告页面 Referer 读取同站只读详情接口。响应为 SUCCESS=true，含 annoTitle、annoDate、annoContent 等字段。未登录、未提交简历、未访问个人信息接口。

可复核入口格式：`https://job.ccb.com/tran/WCCMainPlatV5?CCB_IBSVersion=V5&isAjaxRequest=true&SERVLET_NAME=WCCMainPlatV5&TXCODE=NHR106&annoId=<公告ID>`。每条记录的原始公告 URL 已保留相同 annoId。接口可能需要先访问公告页建立匿名会话，未来若返回空内容或模板，不应继续沿用“实时已核验”状态。

本次逐份读取的是官网完整公告正文，未将搜索片段当证据。附件未全部结构化，因此总部部门细分条件与直属机构上位基本条件仍需联合核对。文字已概括，仅保留岗位关联与需要的准入条件；完整条件以原公告为准。

## 后台门禁

1. 所有记录 evidenceKind=job_requirement、automaticScoringEligible=false，constraintScope=named_employer_cohort_position_only。只允许对相同雇主、同届、同岗位询问或核对明确资格，不得由 roleIds 把条件广播到整个职业。
2. roleIds 是编辑建立的任务索引，不是雇主使用的岗位分类。总部经办岗和通用岗含多种任务，不能把一个公告拆成多个独立招聘样本或保证入职后的岗位分配。
3. 硬性条件、优先条件和未披露必须分开。学校未披露时存储“公告未披露院校层次限制；不能据此推断实际筛选偏好”，不得改写为“不限学校”或“偏好985/211”。
4. 所有记录禁止 offer_probability、admission_difficulty_score、school_prestige_bonus、985_211_or_overseas_advantage_estimate、industry_or_role_wide_eligibility_exclusion、industry_hiring_rate、current_opening_claim 及 individual_resume_collection。
5. 没有同批次同岗位按院校类别拆分的有效申请人数与最终录用人数，不计算985/211/海外背景的录用优势。只有录用者构成时，也只能描述那个已披露群体，不能推断被拒者、投递者或个人概率。
6. 对当前这6份已截止公告，只能作为历史当届申请条件样本。推荐具体投递前，必须复核当前开放状态、岗位版本、截止时间及补充公告。
7. 没有读取上位条件、附件或遇到原文矛盾时，输出“需核验”，不能自动判定某人符合全部条件或排除申请。
8. 国籍、健康、政治条件等敏感条款可作为公告存在性的摘要和人工核验提醒；不得据用户推断的敏感属性自动排序或作就业资格决定。

## 来源层级与数据要求

按有效性优先级维护下列来源。每一类的分母、样本要求、可访问性、更新节奏与偏差已经写入 JSON sourcePlan，供后端审计；不默认展示整份计划。

### 1. 官方岗位与当届招聘公告

用途：只核验具名雇主、部门、地区、届别和岗位的明示条件；建立需要人工复核的条件差距，不作为录用难度指标。

分母：不计算概率；岗位数只能在覆盖规则一致、去重后的职位样本内描述。

样本要求：每条须有实际读到的正文、发布时间或null、适用届别、学历专业、岗位标识及截止状态；同公告多岗位不可重复算独立企业样本。

可访问性与更新：公开HTML、PDF或页面实际使用的匿名公开接口；需登录、验证码或仅搜索片段时不自动入库。 招聘季每周及推荐具体投递前复核；截止、撤回、更正立即更新状态。

有效性检查：核对总公告与子岗位的继承条件；保留优先条件与硬性条件的区别；毕业窗口矛盾保留并停止自动判断。

局限与选择偏差：没有申请人和录用人分母；未写985/211、排名或海外限制不等于不存在实际偏好，亦不得自行填充偏好。 头部企业、可爬取页面与总部岗位更容易进入样本，必须按企业规模、地区、职能和招聘渠道补样。

### 2. 官方匿名化录用汇总与招聘漏斗

用途：在统计口径一致时描述该批次录用者构成；只有匹配的有效申请人数才可计算同批次分组录用率。

分母：构成比分母为该批次全部已披露录用者；录用率分母为同批次同口径有效申请人，且各类别申请与录用计数齐备。

样本要求：岗位、地区、批次、学历、院校分类版本必须一致；区分拟录用、接受offer与实际入职，记录缺失和撤回。

可访问性与更新：优先官方已匿名汇总；若只有个人名单，当前流程仅记录存在与缺口，不转录个人行。 每个招聘批次结束后复核一次，更正公告出现时更新。

有效性检查：核对是否完整公示与分母覆盖；小样本不外推；控制岗位和学历混合产生的构成差异。

局限与选择偏差：只有录用名单或背景比例时不能推断院校优势；不采集个人简历，不把姓名和个人履历入库。 主动披露结果的国企和公开招录更易观察，不能代表私营企业及全部录用渠道。

### 3. 学校分专业毕业去向报告

用途：给出同校同届同专业的历史去向背景，辅助验证路线是否存在。

分母：按原报告定义的该专业毕业生或有效调查样本，二者不能混用。

样本要求：学校、专业、学历、毕业届别、统计时点、分母和去向分类全部可核验；调查数据要有回应率。

可访问性与更新：高校公开报告正文和可读附件；只见发布页而附件不可读则不提取数字。 每年报告发布后更新，保留旧届记录。

有效性检查：核对分母与升学/就业分类；不同专业共用统计组不重复造数；不把学校层次直接转为个人评分。

局限与选择偏差：毕业去向落实率包含升学等去向时不能当作就业率；学校去向数据不能计算某雇主录用概率。 学校地区、专业结构与继续升学比例均会影响去向，头部高校并非全体毕业生样本。

### 4. 国家统计局与其他官方劳动力统计

用途：提供行业规模、变化和统计背景，作为宏观约束。

分母：严格使用原指标的从业者、调查劳动力或单位覆盖分母。

样本要求：记录统计对象、行业分类版本、地区、报告期及修订；城镇单位口径与全体劳动者区分。

可访问性与更新：官方表格及解释文档可公开读取，优先结构化文件。 随月度、季度或年度原系列发布节奏更新。

有效性检查：统计期与发布日期分开；行业与职业不直接等同；不得跨口径拼接排名。

局限与选择偏差：行业平均工资不是应届岗位工资；从业规模、增速和失业率不能直接表示某人录用机会。 单位覆盖和正式就业口径可能遗漏个体、灵活就业与部分小企业。

### 5. 招聘平台研究报告

用途：补充平台内岗位技能、地区与需求变化，只在样本范围内使用。

分母：标明分母是职位条数、招聘人数、企业数、投递次数还是去重求职者。

样本要求：报告需提供样本期、职位/企业/用户去重方式、覆盖地区、样本量和指标定义。

可访问性与更新：公开报告正文可读且有使用权限；不得绕过登录付费或采集个人简历。 每次报告更新时复核，避免把历史季度当实时状态。

有效性检查：跨平台指标不直接合并；招聘薪资与实际收入分开；重复职位与多次投递去重。

局限与选择偏差：平台份额、用户群、广告重复与算法曝光造成选择偏差；没有方法和分母的营销数字不入模。 平台用户和合作雇主不等于全行业总体；头部品牌曝光会放大观察频率。

### 6. 公司财报与行业地位资料

用途：按预先定义的收入、业务规模或市场份额识别候选雇主，并理解其业务，不用来给个人就业概率加分。

分母：市场份额必须有相同市场定义下的总量；营收排名需明确可比企业集合。

样本要求：同业务口径、同地区、同年度可比；集团合并口径与招聘子公司分开。

可访问性与更新：交易所、公司投资者关系页及正式年报；只公开宣传语则保留为待核验。 每年年报更新，重大重组或业务剥离时重审。

有效性检查：头部定义先于选择公司；不把多家集团子公司当独立行业覆盖；盈利增长不等于新增毕业生岗位。

局限与选择偏差：市值、员工总数、营收和品牌热度不是校招容量或录用质量；不能仅凭公司自称领先确定头部。 集中于大型上市公司会遗漏中小企业、专业机构与区域雇主，需另设分层样本。

## 尚未具备的数据

- 尚未建立跨集团、跨地区、跨企业规模的代表性JD样本；当前仅是后端约束样例。
- 尚未取得同岗位、同届、同类别的完整投递—面试—录用漏斗，不支持任何学校背景概率。
- 尚未建立可比财务或市场份额的雇主头部名录；建设银行集团样本不能被解释为经过行业统一口径的排名结果。
- 检索中发现过公开拟录用个人名单，但本轮未转录个人行、未采集简历、未制造录用背景汇总。应优先寻找官方已匿名化汇总。
- 公开资格能够排查具名岗位的条件缺口；它不能回答竞争者质量、实际筛选偏好或个人胜任表现。
