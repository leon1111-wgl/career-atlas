# 当前版本验证记录

验证日期：2026-10-16（UTC+8）。作者：Leon Wang。

## 数据与逻辑

- 45项Python测试、61项Node.js测试通过。涵盖采集回退、地区/专业/学历隔离、SOC精确关联、政策状态、缺失值与招聘条件使用边界。
- 已完成44个专业类别139条具体路径、26个行业研究；原创研究文字不是实测结果，不作为数值训练标签。
- 133组去向样本含587个数值及5个未报告单元格。其中大陆96组217个数值，来自5份已提取的高校官方文档，关联31/44目录类别；不承诺全国代表性。
- 湖北师范57专业人数合计5465；52个完整三值专业的落实率与就业+升学相差不超过0.01个百分点。华东师大本科升学比例分母未完全确认，保留缺口，不反推人数。
- 6条招聘条件均来自建设银行集团且公告期限已过；不是6个独立雇主，不用于院校优势、录用难度或当前空缺判断。
- 编辑壁垒、AI互补、准入评分不参与统计指数；985/211/双非/海外背景、工时和稳定性没有可比数据时保持未知。重复目录映射不会提高统计覆盖。
- 本轮官方统计刷新14路成功、4路保留缓存；原有效日期与状态保留。政策12条已核对，发现与纳入分别处理。

独立审查另修复学校名未进入筛选、博士研究生被误判硕士、多个学历被错误取交集，以及已采集的招聘附加条件未进入模型证据；均有回归验证。

## 页面与模型

现有10组Chrome端到端检查通过。另有8组证据专项检查覆盖全部44专业、26行业、真实去向表、政策状态、缺失提示、职业关联和390px布局；无未捕获JS错误。设计专项覆盖6页×1440/390px，保留已认可配色。

本机Chrome WebGPU加载Qwen并完成能源专业报告的证据筛选约7.2秒，回答保留67名硕士样本和91.04%协议/合同就业数值；无JS错误。这是localhost验收，不能代表公网冷下载速度。模型权重未重训；本轮改善的是资料库、检索和校验。
