## 真实模型推理

在支持 WebGPU 的本机 Chrome 中加载项目自托管的 Qwen3-0.6B 量化权重，成功回答“AI 应用工程师和算法研究有什么区别？”：模型按受限 JSON 协议选择资料片段，程序校验编号后显示原文与引用。未使用远程推理 API。

早期自由生成测试曾出现资料外的资格要求。因此生产界面采用“模型选择证据、程序核验输出”的模式，不把自由生成的事实直接呈现为职业建议。本次测试证明下载与推理链路可运行，不代表所有设备的兼容性或所有问题的回答质量。
