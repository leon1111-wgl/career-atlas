# 中国高校2025届毕业去向补充

本次实际提取两份学校官方报告的15个数据项，写入 `content/graduate-supplement.json`，供页面和检索直接分析，不只提供下载链接。只有确实来自能源专业的样本映射 `majorIds: ["energy"]`；全校样本的 `majorIds` 留空。

## 华中科技大学中欧能源学院

[官方报告网页](https://icare.hust.edu.cn/info/1011/9107.htm) 的明确发布时间为 **2026-03-10**；统计截止 **2025-12-08**。报告明确该学院开设新能源科学与工程专业，2025届全日制学术型硕士67人，不含硕转博8人。

从“毕业生规模”“就业率与毕业去向”及表2提取：协议和合同就业61人、91.04%；升学4人、5.97%；自主创业1人、1.49%；暂未签劳动合同且计划升学1人、1.49%。分母均为67名毕业生；百分比原样保留，四舍五入合计99.99%。计划升学者没有被计为已经升学。

这是单校、单专业、硕士小样本，不是全国能源专业去向，更不是本科或个人录取率。报告中的“就业率”包含升学，所以本补充使用“去向分布”而不把该率用作求职成功概率。

报告后续段落的行业、单位性质和地区占比存在分母不一致的迹象；本次没有据制造业23人、科研技术服务19人等人数，擅自选用61、62或63作为分母来计算行业占比。对能确定分母的去向表做有限提取，比给不确定数字补上精确百分比更可靠。

## 西安电子科技大学

[学校官方发布页](https://job.xidian.edu.cn/news/view/aid/338382/tag/tzgg) 明确发布时间 **2026-01-28 09:36**，不是仅从附件路径推断日期。页面链接的[原始PDF报告](https://job.xidian.edu.cn/attachment/xidian/ueditor/file/20260128/3325_%E8%A5%BF%E5%AE%89%E7%94%B5%E5%AD%90%E7%A7%91%E6%8A%80%E5%A4%A7%E5%AD%A62025%E5%B1%8A%E5%B0%B1%E4%B8%9A%E8%B4%A8%E9%87%8F%E5%B9%B4%E5%BA%A6%E6%8A%A5%E5%91%8A.pdf) 已实际下载读取，50页；用PDF工具提取文字，并将表1-6所在页渲染后目视核验了学历列与数值，避免把研究生列错读成本科列。

报告说明：学校就业数据截至2025年12月；本科毕业生5399人。

- **表1-5，本科去向**：PDF第19页、印刷第14页。单位就业41.51%、升学54.10%、自由职业0.72%、自主创业0.06%、待就业1.98%、暂不就业1.63%，合计100%。分母是全体5399名本科毕业生。
- **表1-6，本科主要行业**：PDF第20页、印刷第15页。信息传输、软件和信息技术服务业39.95%、制造业26.94%、科学研究和技术服务业9.84%、教育业3.87%、金融业2.15%。只提取原表列出的五个行业，合计82.75%，没有捏造一个剩余“其他”类别。

行业表位于“签约流向”章节，其分母是纳入该表的本科签约就业行业样本，**不是全体5399名本科毕业生**。原表未单独披露有效行业样本人数，因此JSON直接写明该人数未披露，不能反推人数。学校全部专业合并样本也不能硬映射为计算机、电子信息等某一专业的结果。

两组分别使用 `groupType: destination` 与 `groupType: industry`，保留各自 `population`、`denominator`、`sourceLocation` 与限制；不跨分母拼接，不把行业当职业，不作为个人就业概率或全国需求预测。报告记录同时保存官方发布页、原始文档地址和实际下载文档SHA-256。

## 验证与接入边界

已验证JSON可解析、专业ID属于当前目录、15项占比均在0–100、所有SOC均为空，以及三组各自的合计和预期一致。未新建空泛链接库，未修改主报告库、采集器、页面或其他代理的文件。供主代理合并后，学院能源样本可用于该专业探索；两组西电全校样本应在研究资讯中显示“全校样本”，不能作为44专业通用分布。
