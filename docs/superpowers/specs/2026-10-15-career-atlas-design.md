# 向野 Career Atlas：中文版设计

## 目标
在 leon1111-wgl 的独立 GitHub 仓库发布一个可持续更新的中美行业、专业、岗位决策平台。中文首发，莫兰迪色，面向年轻人，提供可追溯数据、透明推荐、个人匹配和真正运行的小模型。用户已授权构建和发布，并明确账号与中文优先。

## 架构
- Python 标准库数据管道，公开官方来源：World Bank 年度宏观历史；BLS 职业就业预测及薪资；国家统计局行业工资。抓取状态、数据时期、原始文档哈希、失败保留旧值。
- 原创行业/岗位/专业目录，映射官方分类。数值只由抓取生成，编辑判断独立标注。
- 无框架 ES modules 静态网站，由 GitHub Pages 托管。GitHub Actions 每日抓取、校验、生成 Markdown 报告、发布。调度是数据自动更新，不是此聊天提醒。
- 浏览器本地 Qwen3 0.6B + WebLLM，独立 worker，用户主动加载模型，RAG 检索原创资料和官方快照，证据链接由程序渲染。无远程推理 API，无虚构训练声明。

## 功能
总览、行业探索、行业详情产业链、岗位对比、专业入口、个人偏好、公共部门路径、报告、来源与方法、小模型助手。全国和美国数据分开，汇率不用于薪资比较。岗位原始数字、数据覆盖和缺失一起显示。

## 推荐方法 v1
总权重100：就业增长20、岗位流动/开放15、当地薪酬15、工资增长10、盈利质量10、职业壁垒10、AI互补10、入门可行性10。前三至五维来自数据，后三维编辑评分 1-5 并给出理由。缺失维度不填造；展示可用权重归一化分值、覆盖率、缺失维度、全权重上下界。低覆盖不打总分。框架分不代表就业成功概率。美国 SOC 岗位代理不能当中国预测；中国行业均薪不能当岗位应届薪资。宏观展示背景，不机械影响所有行业。

## 边界
不复制真人口吻，不以 MBTI 决定能力，不许保证录用/收入；考公考编只提供官方信息路径和资格核查清单。不收集敏感身份信息。引用的资本开支、净利润人数未经同口径验证不纳入排名。大模型不执行工具、不读取隐私文件、不改分数；输入资料视为不可信数据。

## 验证
抓取解析、缺失/陈旧传播、评分边界、国家隔离、排名/筛选/对比/下载/移动端、RAG 检索与注入防护、真实小模型加载和生成（环境支持时）、GitHub Actions 及线上字节核验。
