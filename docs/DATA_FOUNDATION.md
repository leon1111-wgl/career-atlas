# 先准备数据，再建立推荐体系

负责人：Leon Wang。当前优先中国大陆。此文件供后台采集、清洗和建模使用，不是面向访客的下载书单。

## 分析单位

不要把“行业—职业—具体职位—专业—院校”混成一张热度榜。每条事实至少保留来源、发布时间、观测期、地区、统计对象、原指标、分母、缺失状态和适用范围。原始数字与编辑解释分开存储。

一个学生的可比就业样本至少要控制毕业届别、学历、专业、目标城市、经验和招聘渠道。一个招聘样本至少要控制雇主集团、部门/岗位、地区和招聘批次。集团子公司的多份公告不计作多个独立行业样本。

## 院校与海外背景分层

为调查设计保留下列字段，不把标签直接变成优劣系数：

- 境内学校：学校唯一标识、学历层次、历史985标记、历史211标记、具体年度双一流建设学科及核验来源；“211非985”和“非985非211”与985分开。双一流学科不等于985或211。
- 招生批次：`province`、`admissionYear`、`subjectTrack`、`batchName`、`programCode`、官方依据。双非一本、双非二本只能在具体省份和招生年份的语境下分析；新合并批次保留原名称，不强塞回旧分类。
- 海外学习：学校、国家/地区、就读时间、学位、专业、授课方式、学习时长、是否为联合培养/分校、学历认证状态（只记录实际已知事实）。
- 如采用排名分层：保留榜单名、版本年份、排名区间和缺失状态；综合排名、学科排名分别存。QS或其他排名只作为可检验的分组变量，不能预设为招聘认可度。
- 分别记录本科院校与最高学历院校，不能只用最后一段教育经历盖掉之前的背景。也不能把海外硕士与境内本科直接混成同学历对照。

当前数据尚不能估计上述分层的净就业优势。没有申请人分母时，录用者中某一类人多，仅说明已观测群体的构成。没有公开数据时保留缺失；不补造个人简历或猜测HR偏好。

## 样本扩充顺序

1. 补齐大陆专业样本缺口：医护、法学、农林、公共管理、技能教育等；同时覆盖不同地区、培养类型、招生背景的学校。先保证分母正确，再扩数量。
2. 将招聘样本从同一银行集团扩展到软件/制造/能源/医疗/教育/专业服务等；每个行业同时纳入大型、区域和中小雇主。头部按同业务口径的市场规模或收入依据识别，不能只凭品牌熟悉度。
3. 获取有样本说明的招聘平台与就业跟踪报告。公开网页受限时使用其公开附件、原页面的匿名接口、学校镜像原文或正式数据接口；无法读到正文时只登记线索，不提取数字。
4. 专门补实际工时、收入分布、申请—录用漏斗；这是目前最限制个性化排序的缺口。访谈只能补充情境，不作为全国比例。
5. 数据达到同口径可比条件后，再设权重、做时间外验证和不同院校/地区分层评估。模型负责解释证据和识别缺口，不能替代观测。

## 综合体系启用条件

当前数字只概括可核对的统计背景。未经样本支持的准入难度、职业壁垒、AI互补、学校优势和工作负荷均不加分。现存编辑文字可作为研究假设，但不是训练标签或真实结果。

未来综合权重必须区分目标：高薪、工作生活平衡、稳定性和进入成本；特征须有清晰单位和缺失处理。训练/验证按时间及雇主集团分隔，避免同一个集团、同校重叠样本泄漏；发布前检查校准、排序稳定性和分层误差。尚未完成这些验证，不能称“准确录用预测”。
