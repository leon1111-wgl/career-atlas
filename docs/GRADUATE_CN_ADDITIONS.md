## 应用和模型接入

顶层与此前补充层一致：`reviewedAt`、`methodology`、`groups`、`reports`，另附 `validation` 保存本轮校验结果。

每个组和报告包含 `school: {name, aliases, domain}`。华东师大采用 `ecnu.edu.cn`，湖北师大采用 `hbnu.edu.cn`。`schoolScope` 分为 `institution` 与 `major`，学校名称和域名用于筛选，不代表专业数据可以跨学校通用。

`educationLevel` 分别使用 `bachelor`、`master`、`doctorate`、`mixed` 或 `unspecified`；后两者含义不同。`studyMode` 区分全日制、全体及未明示学习方式。`publishedAt` 是发布日期，`period` 是届别，`asOf` 是统计截止，不能以发布年份替换届别。

`dataKind` 使用 `destination_status`、`further_study_rate` 和 `outcome_indicators`。湖北57组统一为 `outcome_indicators`，`metric` 为“分专业毕业去向指标（不相加）”。每条记录需读取 `metric`、`population`、`limitations` 和行内 `metricKey`；兼容字段 `occupation` 在这里是指标名称，不是职业名称。全部SOC为 `null`。显示数值前应检查 `share` 是否为空，禁止自动转成零。

湖北组的三列存在包含关系：落实率包含就业与升学，不能把三条比例相加。`rowsMutuallyExclusive: false` 与 `aggregationPolicy` 明示这一点。学校总体和学历子群也不得相加。就业分类包含自由职业及其他录用形式，不应解释为签约率、稳定就业或专业对口。

没有提取华东师大分母未明示的行业、单位性质和地域比例，也没有将单校样本推广为全国规律。蚌埠医科大学的学院页面只用于检索探索，本轮未加入资料，避免扩张为未经完整分母核验的数据。
