## 如何解读

- 增长和薪资各自回答不同问题。行业工资较高，并不代表毕业生容易进入。
- 相同统计门类下的细分行业可能共用数据，人工智能、软件和通信不会因此被视为相同职业。
- 中国缺少本项目可持续抓取的同口径职业就业预测；缺失项保持缺失。
- 盈利质量、AI 专属资本开支和行业人均净利润尚无完整可比样本，不进入数字评分。
- 轻量问题分类器与本地资料库整理回答；可选 Qwen3 0.6B 筛选依据，均不修改统计值或评分规则。

## 下一步行动

1. 选两个行业、三个岗位，阅读任务与入门要求。
2. 在目标城市收集真实招聘要求，核对是否接受应届和跨专业。
3. 约一位从业者访谈，完成一个能验证兴趣的小项目。
4. 用一周的体验修正选择，不把一次评分当结论。
